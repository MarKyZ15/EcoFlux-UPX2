# EcoFlux ♻️

Projeto desenvolvido para a disciplina de **UPX2 - Usina de Projetos Experimentais II** do curso de Análise e Desenvolvimento de Sistemas (Facens - 2026).

## 🚀 Sobre o Projeto
O EcoFlux é um ecossistema digital para monitoramento de reciclagem condominial, focado em governança de dados e sustentabilidade. O sistema utiliza uma inteligência de software robusta baseada em **Java/Spring Boot** para emular fluxos de telemetria predial, permitindo o acompanhamento de indicadores de impacto ecológico em tempo real.

## 🛠️ Tecnologias Utilizadas
- **Back-end:** Java 17, Spring Boot (MVC, JPA, @Scheduled).
- **Banco de Dados:** H2 Database (In-Memory).
- **Front-end:** Thymeleaf, JavaScript (Fetch API), Chart.js.
- **Ferramentas:** Git, Trello, Figma.

## 📋 Como rodar o projeto
1. Clone o repositório ou baixe o código fonte.
2. Importe o projeto como **Maven** no seu IntelliJ.
3. Execute a classe principal (`EcoFluxApplication`).
4. Acesse o dashboard em: `http://localhost:8080`
